Qué añade la conversión

  • Renderer nativo de SCREEN 2 con caché y presentación sincronizada con VBlank.
  • Mapa de seguimiento móvil centrado en Fred, marcado mediante un sprite.
  • Redefinición estable y repetición retrasada conservando el primer disparo inmediato.
  • Adaptación no bloqueante de las rutinas de beeper al PSG.
  • Objetos sin posiciones duplicadas, el desensamblado y las fuentes del parche.

Araubi completó el juego de principio a fin. Las pruebas automáticas cubren renderizado, mapa, objetos, transiciones, C-BIOS y cadencia del disparo.

Aplicar el IPS

Aporta tu snapshot Fred_1984_Quicksilva_re_release.z80, SHA-256 05e2437c...8271e0:

python tools\normalize.py
python tools\make_ips.py apply build\Fred_MSX1_base.rom patch\Fred_MSX1.ips build\Fred_MSX1.rom

El resultado debe tener SHA-256 4f5dc53e...4c59b1. No se distribuye el snapshot ni la ROM.
